# creatorloop

**Открытая AI-студия контента для авторов в Instagram на базе Claude и официального Instagram API.**

Анализ того, что работает → создание Reels и каруселей → публикация или очередь → разбор результатов через 24 и 72 часа.
Всё — в чате с Claude.

- **Данные вместо догадок:** лучшие и худшие посты с хуками, сравнение форматов, подписки на 1000 охвата,
  время просмотра Reels, лучшие день и час, какие подписи работают.
- **Конкуренты легально:** отслеживание, история подписчиков, посты, которые набрали в N раз больше медианы,
  разбор любого публичного поста по ссылке.
- **Создание контента:** шаблон Reels на Remotion с автопроверками, своя музыка, 3D-объекты с лицензиями.
- **Безопасная публикация:** превью перед каждой публикацией, очередь с защитой от изменённых файлов,
  отчёты через 24/72 часа, ответы на комментарии только после вашего «да».
- **Только официальный API:** без скрейпинга и риска для аккаунта.

## Быстрый старт

Нужны [uv](https://docs.astral.sh/uv/getting-started/installation/), Claude Desktop, аккаунт Instagram типа
**Business** или **Creator**, привязанная **Facebook-страница** и своё приложение Meta
([гайд, на английском](docs/meta-setup.md)).

```bash
uvx --from creatorloop creatorloop-setup
```

Команда подключит Claude Desktop и откроет страницу настройки в браузере: введите **App ID** и **App Secret**
своего приложения, нажмите **«Продолжить через Facebook»** — готово. Затем спросите Claude: *«Как зашли мои
последние 10 постов и что мне публиковать дальше?»* Уже в Claude? Попросите *«подключи мой Instagram»* — откроется
та же страница. Секрет и токен вводятся только на ней, не в чат.

### Установка в один клик (Claude Desktop)

Не хотите открывать терминал? Скачайте файл `.mcpb` из
[последнего релиза](https://github.com/pandich93/creatorloop/releases/latest) и откройте его двойным щелчком (или
перетащите в Claude Desktop → Settings → Extensions). Python и зависимости Claude Desktop поставит сам, поэтому первый
запуск займёт около минуты. Два необязательных поля оставьте пустыми и попросите Claude *«подключи мой Instagram»* —
откроется та же страница настройки. Заполняйте их, только если у вас уже есть токен и ID аккаунта: значения из этих
полей важнее страницы настройки. Если Claude Desktop не находит `uv`, установите [uv](https://docs.astral.sh/uv/getting-started/installation/)
и перезапустите Claude Desktop.
